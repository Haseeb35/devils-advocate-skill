# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and critique ideas rather than people — the same standard the skill itself is held to. Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it privately to the maintainer through GitHub ([@Haseeb35](https://github.com/Haseeb35)) or via the repository's private reporting channel. All reports are reviewed and kept confidential.

Maintainers may remove, edit or reject contributions that do not follow this code, and may temporarily or permanently ban contributors for behaviour they deem harmful.
